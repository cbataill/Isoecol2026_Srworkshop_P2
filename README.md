# IsoEcol 2026 Sr workshop: Module 2

Building a random forest bioavailable 87Sr/86Sr isoscape for South Africa.

Website: https://cbataill.github.io/Isoecol2026_Srworkshop_P2

- The site is built with [Quarto](https://quarto.org) and rendered into `docs/` for GitHub Pages.
- Code chunks are shown but not run (`eval: false` in `_quarto.yml`); the figures in `images/` come from a pre-computed run.
- Data and the full script: [`Module2_isoscape/`](Module2_isoscape) (training data, ~60 clipped rasters, pre-computed outputs). Open `Script_RF_isoscape_SouthAfrica.Rmd` in RStudio and set the working directory to that folder.
- Module 3 (geographic assignment): https://meganreich.github.io/Isoecol2026_Srworkshop_P3/

To edit: change the `.qmd` files, run `quarto render`, commit and push.
