IsoEcol 2026: Strontium isotope geolocation for terrestrial ecology

Module 2: building a random forest ⁸⁷Sr/⁸⁶Sr isoscape for South Africa

Author

Clement Bataille

Published

October 9, 2026

Welcome

Welcome to Module 2 of our workshop, “Strontium isotope geolocation for terrestrial ecology,” held at The 14th International Conference on the Applications of Stable Isotope Techniques to Ecological Studies (ISOECOL 2026) in Hong Kong!

In Module 1, Chris showed how to screen bioavailable ⁸⁷Sr/⁸⁶Sr data with IsoBank and the ARDUOUS template. Today, we use a different, already-cleaned dataset for South Africa (not the one screened in Module 1) to build a bioavailable ⁸⁷Sr/⁸⁶Sr isoscape with random forest regression. In Module 3, Megan will use this isoscape to find where painted lady butterflies came from.

How to use this site

Each section of the workshop has its own page, listed in the sidebar on the left. We’ll go through them together, but you’re welcome to work at your own pace. If you get lost, use the sidebar or the search box to find the section we’re on.

Throughout the pages you’ll find 🦋 Think · Pair · Share breaks. Stop there, think on your own, discuss with your neighbour, then share with the room. Open the “Things you might have noticed” box only after the discussion!

What you’ll learn

By the end of this module you will be able to:

  • Build a regression matrix from bioavailable ⁸⁷Sr/⁸⁶Sr data and geospatial covariates
  • Choose covariates using process knowledge, and deal with correlated covariates
  • Select predictors and evaluate a random forest model with random and spatial cross-validation
  • Interpret variable importance and partial dependence plots
  • Map the isoscape and its uncertainty with a quantile random forest

Before the workshop

Please set up before you arrive
  1. Install a recent version of R.
  2. Install RStudio Desktop.
  3. Run the code below in the RStudio console to install the packages we’ll use.
  4. Download the workshop data (below). The rasters are ~350 MB, so please don’t wait for the conference Wi-Fi!
install.packages(c("terra", "sf", "rnaturalearth", "rnaturalearthdata", "caret", "VSURF",
                   "ranger", "corrplot", "viridis", "patchwork", "ggplot2", "pdp", "tidyverse"))

Get the data and the script

  • Data and script: everything is in the Module2_isoscape folder of this site’s repository. On the repository page, click Code → Download ZIP, unzip it and keep the Module2_isoscape folder (~400 MB). The data are also on PURR.
  • Script only: download Script_RF_isoscape_SouthAfrica.Rmd. Every code chunk on this site comes from this script.

Folder organisation

Module2_isoscape/
├─ Script_RF_isoscape_SouthAfrica.Rmd
├─ Data/
│   └─ SouthAfrica_bioavailable_Sr_ARDUOUS.csv
├─ Project_Raster/
│   ├─ clipped_za/      (~60 rasters, Eckert IV, 1 km)
│   └─ neighbourhood/   (created by the script)
└─ Output/              (created by the script; pre-computed results are included)
Running the code
  1. Open Script_RF_isoscape_SouthAfrica.Rmd in RStudio.
  2. Session → Set Working Directory → To Source File Location.
  3. Run the setup chunk: it installs any missing packages.
  4. Run chunk by chunk (Ctrl+Shift+Enter) and look at each output. You can also copy the code from this site into the console.

The whole script takes ~15–20 min on a laptop. The two slow steps are VSURF (~8 min, Step 4.3) and the isoscape prediction (~5 min, Step 5.2). If your laptop is slow, load the pre-computed results from Output/.

The figures on this site come from a pre-computed run of the script. Your results should be very close, but small differences are normal (random seeds, package versions).
